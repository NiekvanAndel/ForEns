One-line: the brand's only button shape — always a full pill, never a rounded rectangle.

```jsx
<Button variant="primary" icon={<ArrowRight/>}>Bekijk mijn regen</Button>
<Button variant="ghost-dark" size="sm">Hoe werkt het?</Button>
```

- `primary` on cream or navy; `ghost` only on navy/hero; `ghost-dark` only on cream/white; `white` only inside the green CTA band.
- Hover: primary brightens 1.06 and lifts 1px; ghosts raise border opacity. Never change the label colour on hover.
