One-line: one measurement per card, always in a two-column grid on cream.

```jsx
<MetricCard label="Total precipitation" value="1,6" unit="mm" footnote="24 hour"/>
<MetricCard label="Min. temperature 150cm" value="15,6" unit="°C" footnote="Today" tone="cool"/>
```
Missing readings render an em-dash in muted grey — never "0" and never hidden.
