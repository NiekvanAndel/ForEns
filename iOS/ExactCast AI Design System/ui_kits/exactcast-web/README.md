# ExactCast AI — marketing site UI kit

Three click-through pages built from the same tokens and components as the app kit.
The nav in the header switches page; nothing else is wired.

| File | Page |
| --- | --- |
| `index.html` | shell, header/footer, page routing |
| `HeroSection.jsx` | navy hero with 40px bottom radius, phone pair, overlapping trust bar |
| `HomePage.jsx` | use cases, how-it-works layers, comparison table, status legend, network map, specs, testimonials, FAQ, CTA band |
| `PricingPage.jsx` | sub-hero, three plans, "what is a location" callout, postcode check, subscription FAQ |
| `NetworkPage.jsx` | sub-hero, local-variation proof, dark accuracy panel with honest caveat, measurement specs |

## Fidelity notes
Layout, spacing (112px sections, 1280px max, 32px gutter), hero radius, trust-bar overlap (−44px),
comparison-table treatment, plan cards, callout and FAQ patterns are transcribed from
`uploads/agroexact-lokaal-weer-voorbeeld.html`. Copy is rewritten for a consumer audience;
unconfirmed claims keep the source's amber "te bevestigen" badge convention.
